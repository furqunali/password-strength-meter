# 🔐 Password Strength Meter

A Python tool that **scores password strength** against common security rules and returns a Weak / Medium / Strong verdict.

## Checks

- Minimum length (8+ characters)
- Upper- and lower-case letters
- At least one digit
- At least one special character (`@ $ ! % * ? &`)

## Run it

```bash
python "Password Strenght Meter.py.py"
```

> Uses Python's `re` module for pattern checks — a compact intro to regex-based validation.
